# Video assets

- `hero-section.mp4` — the provided Hero export. Used as the Hero background (`src/components/Hero/HeroVideo.jsx`) and, as a placeholder, in the Showreel player (`src/components/Showreel/ShowreelVideo.jsx`).

To give the Showreel section its own cut, drop a file at `showreel.mp4` here and update `VIDEO_SRC` in `ShowreelVideo.jsx`.
